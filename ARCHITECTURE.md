# Arquitectura actual

**Actualizado:** 2026-11-04.

El checkout contiene un harness documental: instrucciones de gobierno, definición de producto en borrador, propuestas de decisiones y planificación. No hay código de aplicación, manifiesto de dependencias, build, suite de pruebas ni servicio ejecutable. Esta revisión no acredita ningún despliegue de MiMiniApp, Worker, dominio o pipeline configurado.

Las [decisiones técnicas](docs/design-docs/index.md) están en `Propuesta`. El objetivo de Astro estático, React/TypeScript, Tailwind y Cloudflare se documenta en [arquitectura objetivo propuesta](docs/design-docs/architecture-target.md), separado de lo implementado. La disponibilidad de Node u otras herramientas en el entorno cloud no constituye una decisión de stack.

Actualizar este mapa cuando haya implementación y evidencia de build, ejecución o despliegue. No trasladar aquí componentes propuestos como si ya existieran.
